# Personal Profile Card 🚀

 A responsive, interactive personal profile card to showcase my skills, and professional links. 

## ✨ Features
*   **Clean UI/UX:** A modern, minimal design with a beautiful background gradient.
*   **Flexbox Layout:** Structured using CSS Flexbox for alignment of badges and action buttons.
*   **Interactive Elements:** Smooth hover transitions and box-shadow effects on skill badges and links.
*   **Status Indicator:** A status dot indicating "Available for Work."

## 🛠️ Tech Stack
*   **HTML5:** Semantic markup and structure.
*   **CSS3:** Custom styling, gradients, pseudo-classes (`:hover`), and positioning.
